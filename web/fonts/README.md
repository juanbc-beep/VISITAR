# IBM Plex Sans / Sans Condensed / Mono (auto-hospedadas)

`IBMPlexSans-{Regular,Medium,Bold}.woff2`, `IBMPlexSansCondensed-Bold.woff2`
y `IBMPlexMono-{Regular,Bold}.woff2`, subconjunto `latin` (cubre acentos y
ñ del español), tomados de Google Fonts
(`fonts.googleapis.com/css2?family=IBM+Plex+Sans` / `+Sans+Condensed` /
`+Mono`).

Una sola familia para toda la app —cuerpo, etiquetas y códigos—, diseñada
en conjunto por IBM/Bold Monday para pantallas de datos técnicos densos.
Se auto-hospedan en vez de cargarse desde Google en cada visita para no
sumar una petición externa a la CSP (`font-src 'self'` se mantiene sin
tocar) ni filtrar la IP del usuario a un tercero en cada carga.
